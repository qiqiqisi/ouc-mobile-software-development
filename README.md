## 游戏主题

- 玩家：黑猫哈吉米
- 箱子：猫罐头
- 目标位置：猫饭碗
- 墙体：快递纸箱

四个关卡仍使用课程实验的 8×8 地图结构，并保留步数、推动次数、撤回、重开、本地最佳成绩和通关后查看标准路线等功能。

## Web 版

Web 版不需要微信 AppID，手机和电脑浏览器均可直接运行。

主要迁移：

- 小程序 Canvas 2D → 浏览器 Canvas 2D
- `wx.setStorageSync()` → `localStorage`
- 小程序页面跳转 → 单页 Hash 路由
- `bindtap` / 触摸事件 → Click / Pointer Events
- 额外支持电脑方向键和 WASD

部署后访问：

`https://qiqiqisi.github.io/ouc-mobile-software-development/lab04/`

Web 版的关卡、地图、标准路线、通关规则和主要文案与小程序版保持一致。
