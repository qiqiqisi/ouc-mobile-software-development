## 一、实验内容

### 1. 实验环境

本次实验在 Windows 系统下完成，使用微信开发者工具 Stable 2.01.2510260 进行小程序的创建、编写和调试。登录开发者工具后，先熟悉了小程序项目的创建入口和基本界面。

![图1 微信开发者工具环境](images/环境.png)

### 2. 使用快速启动模板创建小程序

首先创建第一个项目 `first_test`。创建时使用测试号，后端服务选择“不使用云服务”，并选择官方的 **JS-基础模板**。

![图2 使用 JS 基础模板创建小程序](images/使用模板创建.png)

项目创建成功后，开发者工具自动生成了 `pages`、`app.js`、`app.json`、`app.wxss` 等文件，并能够直接在模拟器中运行。

![图3 模板项目初始界面](images/模板的界面.png)

接着对模板项目进行简单修改。先在 `index.wxml` 中重新组织页面内容，并使用 `{{motto}}` 将 JavaScript 中的数据绑定到页面上。

![图4 修改 index.wxml](images/模板修改wxml.png)

然后在 `index.js` 的 `data` 中修改 `motto` 的内容，并增加 `count` 变量，用来记录按钮的点击次数。

![图5 在 data 中增加 count 变量](images/模板修改js.png)

之后编写 `addCount()` 方法。每点击一次按钮，就通过 `setData()` 将 `count` 加 1，页面中的点击次数也会同步变化。

![图6 编写 addCount 方法](images/模板修改js2.png)

最后在 `index.wxss` 中设置标题、正文和点击次数的字号、间距等样式，使页面显示更加清楚。

![图7 修改页面基本样式](images/模板修改ss.png)

![图8 增加点击次数的样式](images/模板修改ss2.png)

修改完成后，页面可以正常显示标题、点击次数、按钮和文字，并且点击按钮后数字会不断增加。

![图9 模板项目最终运行结果](images/模板结果.png)

通过这一部分，我初步理解了 `WXML`、`WXSS` 和 `JavaScript` 的基本作用：`WXML` 用来描述页面结构，`WXSS` 用来设置页面样式，`JavaScript` 用来保存数据和处理交互。

### 3. 不使用模板创建小程序

第二部分重新创建项目 `second_test`。这次同样使用测试号并选择“不使用云服务”，但模板选择改为 **“不使用模板”**。

![图10 不使用模板创建 second_test](images/不使用模板.png)

在 `index.wxml` 中添加一段文本和一个按钮。文本通过 `{{message}}` 读取 JavaScript 中的数据，按钮通过 `bindtap="changeText"` 绑定点击事件。

![图11 编写 index.wxml](images/不用模板wxml.png)

最开始在 `index.js` 中将 `message` 设置为 `Hello World`。点击按钮后，`changeText()` 使用 `setData()` 将文字修改为 `Hello WeChat`。

![图12 第一次实现文字修改](images/不用模板js.png)

为了让按钮再次点击时能够恢复为 `Hello World`，又增加了一个 `flag` 变量。`flag=0` 时显示 `Hello World`，点击后将 `flag` 改为 1 并显示 `Hello WeChat`；再次点击时把 `flag` 改回 0，从而实现两种文字之间的反复切换。

![图13 使用 flag 实现文字反复切换](images/不用模板js2.png)

在 `index.wxss` 中设置页面排列方式、文字大小、间距和按钮宽度，使文字和按钮的布局更加清楚。

![图14 second_test 页面样式](images/不用模板ss.png)

至此，不使用模板创建的小程序可以正常运行，并且按钮能够在 `Hello World` 和 `Hello WeChat` 两种文字之间反复切换。

## 二、问题总结与体会

实验中主要遇到的问题是，最开始按钮只能把 `Hello World` 修改成 `Hello WeChat`，再次点击时文字不会恢复。后来增加了 `flag` 变量，用 0 和 1 记录当前状态，再通过 `if...else` 判断当前状态，实现了两种文字的反复切换。

通过本次实验，我对微信小程序的基本结构有了初步认识。`WXML` 主要负责页面内容，`WXSS` 负责页面样式，`JavaScript` 负责数据和点击事件；使用 `setData()` 修改数据后，页面内容也会同步更新。相比直接使用模板，从“不使用模板”开始编写第二个小程序让我更清楚地理解了这些文件之间的关系。
